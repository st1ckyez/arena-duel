# ARENA DUEL — лоуполи-шутер для двоих

3D-шутер на Three.js: **игра по сети** (WebRTC, каждый на своём компьютере) или локальный сплит-скрин за одним компьютером. Без сборки и установки зависимостей.

## Запуск

Каждый игрок запускает игру у себя (нужен любой локальный веб-сервер, т.к. используются ES-модули):

```
python -m http.server 8741
```

Открыть в браузере: http://localhost:8741

## Игра по сети

1. Первый игрок: **Игра по сети → Создать игру** — сразу попадает на карту (разминка) и видит код комнаты из 5 символов.
2. Второй игрок (на своём компьютере): **Игра по сети → Присоединиться** — ввести код.
3. При подключении обоих телепортирует на спауны, идёт отсчёт 5 секунд — и бой начинается.
4. Соединение устанавливается напрямую между игроками (WebRTC / PeerJS). Нужен интернет; в редких случаях строгий NAT может не пропустить прямое соединение.

Карта — здание: центральный зал со световым люком и колоннами, четыре угловые комнаты с дверными проёмами, укрытия, ящики и бочки.

### Управление (по сети)

Вид от первого лица, как в классических FPS:

- **WASD** — движение
- **Мышь** — обзор и прицел, включая вертикаль (клик по экрану захватывает мышь)
- **ЛКМ** — огонь
- **Space** — прыжок
- **C** — присед (медленнее, но ниже профиль)
- **Esc** — меню

## Локальный режим (один экран)

| Действие | Игрок 1 (синий) | Игрок 2 (красный) |
|---|---|---|
| Вперёд / назад | W / S | ↑ / ↓ |
| Поворот | A / D | ← / → |
| Шаг вбок | Q / E | , / . |
| Огонь | Space | Enter |

## Правила

- Урон с попадания — 20 HP, всего 100 HP.
- Убитый возрождается через 3 секунды в самой дальней от противника точке.
- Аптечки восстанавливают 50 HP и появляются снова через 12 секунд.
- Побеждает первый, кто наберёт **10 фрагов**.
